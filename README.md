Vishu_Craft - Online Shopping Store
📌 Project Overview

Vishu_Craft is a simple and modern online shopping website created for showcasing decorative products, artificial flowers, leaves, and home decorations.
This project was developed using HTML, CSS, and JavaScript.

The website includes:

Home page
Navigation bar
Product section
Login page
Image slider/banner
About and contact sections

🚀 Features
Responsive navigation menu
Attractive homepage banner
Product showcase section
Login page integration
Smooth image display/slider
Simple and user-friendly interface

🛠️ Technologies Used
HTML5
CSS3
JavaScript
